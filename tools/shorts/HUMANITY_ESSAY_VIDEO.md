# AI 허공장 — 인류에게 남기는 글 전용 영상엔진

이 경로는 기존 30초 YouTube Shorts 자동화와 별개입니다. NOW Mind Search V3.0 홈페이지, 매일 글 발행 일정, 기존 Shorts 워크플로는 변경하지 않습니다.

## 확정된 기본 규격
- 90초(1분 30초), 1 FPS, 90프레임
- **글을 완성하고 내용 검토 후 그 글에 맞춰 실사형 이미지 15장을 새로 생성(장면당 6초)**\n- **기존 영상의 사진 재사용 금지. 이미지 생성 실패 시 영상 제작 중단**
- 한국어 글 전체 및 영어 번역 전체를 장면별 상단 자막으로 표시
- **자막 배경 완전 투명(배경 박스 없음)**, 가독성을 위한 글자 테두리와 약한 그림자만 적용
- 자체 합성한 **90초 감동적인 시네마틱 오케스트라풍 경음악**(가사 없음). 0~30초 피아노·첼로, 30~60초 현악·목관 확장, 60~80초 금관·타악 포함 절정, 80~90초 현악 마무리. **실제 오케스트라 녹음이나 고급 AI 음악 생성이 아닌 코드 합성 근사 음색**
- 세로 540×960, MP4(H.264/AAC)
- **유튜브 업로드 없음. 승인 전 공개 금지.**

설정: `tools/shorts/humanity_essay_90s.json`
제작 코드: `tools/shorts/humanity_essay_video.py`

## 실행
1. `story.json` 파일에 `{"title":"제목","ko":"한국어 원문 전체","en":"영어 전체 번역"}` 입력
2. 새 작품 전용 **빈** `photos/` 폴더 준비(기존 이미지 사용 금지)
3. `python tools/shorts/humanity_essay_video.py --story story.json --images-dir photos --output-dir output --generate-images`
4. ffmpeg/ffprobe, Pillow, NanumGothic 폰트 필요

OpenAI 이미지 API 키가 필수이며 **15장 이미지 API 호출에는 별도 비용이 발생할 수 있습니다.** 생성된 사진은 글의 장면과 인물·배경 일관성을 검수하세요. 이미지 생성이 불가능하면 기존 사진으로 대체하지 않고 오류로 중단합니다.

## 주의
- 1FPS는 정지사진 중심 영상입니다. 실제 인물 동작을 생성하지 않습니다.
- 원문 전체와 영어 번역을 90초 안에 표시하므로 글 길이에 따라 자막이 빠르게 넘어갈 수 있습니다.
- 이미지 자동 생성은 API 키·결제·모델 접근 권한에 따라 실패할 수 있습니다.
- 현재 이 스크립트는 **수동 실행용**이며, 매일 글 발행과 자동으로 연결하거나 YouTube에 게시하지 않습니다.

## 새로운 오케스트라 음악 생성엔진
- `tools/shorts/orchestra_composer.py`: 글의 내용으로 분위기를 판정하고 오리지널 7트랙 MIDI 악보를 생성합니다.
- 출력: `original_orchestra_90s.mid`, `original_orchestra_90s.wav`, `music_manifest.json`.
- 0~30초 피아노·첼로, 30~60초 현악기·플루트, 60~80초 호른·팀파니 절정, 80~90초 여운.
- 고품질 악기 음색: FluidSynth 설치 및 합법적으로 사용 가능한 SoundFont 파일을 준비한 뒤 `HEOGONGJANG_SOUNDFONT=/path/to/soundfont.sf2` 환경변수 지정.
- SoundFont/FluidSynth가 없으면 자체 파형 합성으로 자동 대체합니다. 대체 음색은 실제 오케스트라와 다릅니다.
- 단독 실행: `python tools/shorts/orchestra_composer.py --story story.json --output-dir music_output`.
- 영상 제작 코드에서도 새 음악 생성기를 자동 호출합니다. 영상에 사용된 음악은 90초 WAV입니다.
- MIDI 및 음악은 글에 따라 새로 구성됩니다. 기존 상용 음원이나 녹음은 포함하지 않습니다.
- **상태**: GitHub 코드 통합 완료. 실제 실행 및 음질 검증은 배포 환경에서 별도로 필요합니다.

## 필수: 원문을 먼저 읽고 그림 제작
1. **AI 허공장이 쓴 한국어 원문 전체를 먼저 분석**합니다. 등장인물, 장소, 계절, 소품, 사건과 시간 순서를 파악합니다.
2. `story_scene_planner.py`가 원문에 근거한 **15개 장면 구성표**를 만들고 `story_scene_plan.json`으로 저장합니다.
3. 이미지는 반드시 해당 장면의 설명과 인물·장소 일관성에 근거해 **15장 각각 새로 생성**합니다. 원문에 없는 씨앗·나무·다른 이야기로 바꾸지 않습니다.
4. 생성 직후 이미지 분석 모델이 장면과 일치하는지 검사합니다. **불일치·포스터·콜라주 판정 시 해당 이미지를 삭제하고 MP4 제작을 중단**합니다. 자동 재시도는 하지 않습니다.
5. 15개 장면이 모두 통과한 뒤 자막·오케스트라 음악을 합성해 MP4로 출력합니다.

필요: OpenAI API 키, 이미지 생성 모델과 이미지 검증용 비전 모델 접근권한. 이미지 및 텍스트 분석 호출에 별도 요금이 발생할 수 있습니다. 자동 판정은 완전하지 않으므로 최종 육안 검수가 권장됩니다. **코드 반영 완료, 실제 전체 실행은 아직 검증하지 않았습니다.**
