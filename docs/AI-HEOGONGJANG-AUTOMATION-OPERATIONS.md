## 운영 원칙
1. 사용자의 명시적 승인 없이 자동화의 중지, 삭제, 일정 변경을 수행하지 않는다.
2. 창작·발행 작업은 날짜 기준 중복 여부를 확인한다.
3. GitHub 저장 성공과 공개 사이트 반영 성공을 구분한다.
4. 실패 또는 확인 불가를 성공으로 보고하지 않는다.
5. 민감한 토큰·비밀번호·비공개 개인정보는 공개 저장소에 기록하지 않는다.
6. 채팅 삭제만으로 작업이 중지된다고 가정하지 않으며, 실제 자동화 활성 상태를 별도로 확인한다.

## 복구 절차
1. ChatGPT 자동화 관리 화면에서 등록된 작업 목록 및 활성 상태를 확인한다.
2. 이 문서의 일정과 비교해 누락·중지 작업을 확인한다.
3. 사용자 승인을 얻어 기존 작업을 재활성화한다. 누락된 작업은 기존 프롬프트·대상 저장소·일정·권한을 확인한 후 재생성한다.
4. 각 작업을 시험 실행하고 GitHub 변경, Google Drive 백업, 공개 배포를 개별 검증한다.
5. 실패한 작업은 오류와 재시도 조건을 기록한다.

## 제한 사항
- GitHub 문서는 운영 설계와 일정의 독립 사본일 뿐, ChatGPT 자동화의 내부 등록 정보·권한·실행 환경을 완전히 백업하지 않는다.
- 자동화가 중지된 원인은 확인되지 않았다. 사용자가 중지를 요청했다는 증거도 확인되지 않았다.
- 채팅 삭제나 계정 접근 상실 이후에도 모든 작업이 계속 실행된다는 보장은 없다.
