# AI 허공장 자율 진화 실험실 v0.1

## 목적
매일 정해진 시각에 자동 평가를 실행하고 결과를 GitHub에 누적합니다.

## 현재 가능한 일
- 웹사이트와 영상 스튜디오의 기본 파일 존재 여부 검사
- 재현 가능한 준비도 점수 계산
- 이전 실행 대비 변화 기록
- GitHub Actions 실행 이력 및 JSON 결과 보존

## 아직 구현되지 않은 일
- 사진과 3D 얼굴의 유사도 평가
- 자연스러운 움직임의 정량 평가
- 3D 모델 또는 영상의 자동 생성·학습
- 평가 결과를 이용한 모델 가중치 업데이트
- 개선된 모델의 자동 배포

## 안전 원칙
검증되지 않은 3D 모델이나 영상을 운영 홈페이지에 자동 배포하지 않습니다.
실제 품질 개선을 주장하려면 동일한 테스트 데이터와 평가 기준에서 개선을 확인해야 합니다.
