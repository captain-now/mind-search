# 허공장 무료 경음악 제작 엔진 v0.1

GitHub Actions에서 FluidSynth + FluidR3 SoundFont + FFmpeg를 사용해 **직접 작성한 원곡**을 MIDI → MP3(320kbps) 및 AAC(192kbps)로 렌더링합니다.

- 매일 10:40 KST 자동 실행을 예약하며, GitHub Actions가 비활성화되거나 사용량 한도를 초과하면 실행되지 않을 수 있습니다.
- 수동 실행: GitHub → Actions → **Heogongjang Original Instrumental** → Run workflow
- 결과 확인: 실행 상세 페이지 → Artifacts → `heogongjang-original-music`
- 보관 기간: 14일. 장기 보관은 별도 백업이 필요합니다.
- 길이: 약 50.53초 (쇼츠 규격 30–80초 범위)
- 아직 사진·한영 자막·영상 합성은 연결되지 않았습니다.
- SoundFont는 GitHub 서버에 설치되는 시스템 패키지를 사용합니다. 음원 재배포 및 상업적 사용은 해당 SoundFont 라이선스를 별도 확인해야 합니다.
- 이 엔진은 기존 곡을 복제하지 않으며, 별도 자동 게시 기능이 없습니다.
